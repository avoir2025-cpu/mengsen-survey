# 萌森小水手補給站｜互動問卷網頁 v1

2026/11/15 家扶南高雄愛心園遊會用。客人在 LINE 裡開啟，填 8 題旅遊問卷，看到夢想旅程試算，拿到兌換卡（$80＋羅盤 1 次）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 問卷網頁本體（單一檔案，手機優先） |
| `logo.svg` | 萌森 LOGO（金色向量檔） |
| `apps_script.gs` | Google 試算表後端：收名單、記兌換時間 |

## 先看示範

直接開 `index.html`（或網址加 `?demo=1`）就是示範模式：
- 上方黃色列可以切換「已加入／未加入好友」、清除重來
- 資料只存在這支手機，不會送到任何地方

## 上線步驟

### 1. 試算表後端
1. 開一份新的 Google 試算表（用萌森的帳號）
2. 擴充功能 → Apps Script，把 `apps_script.gs` 整份貼上
3. 部署 → 新增部署作業 → 類型選「網頁應用程式」
   - 執行身分：我
   - 誰可以存取：所有人
4. 複製網址，貼到 `index.html` 的 `CONFIG.API_URL`
5. 第一筆資料進來時，會自動建立「名單」分頁

### 2. LINE 設定
1. LINE Developers 建一個 **LINE Login channel**，要跟萌森官方帳號在同一個 Provider
2. 在 channel 的基本設定裡，連結萌森官方帳號（網站才讀得到「是否已加好友」）
3. 新增 LIFF app
   - Size：Full
   - Endpoint URL：網頁上線後的 https 網址
   - Scope：`profile`、`openid`
   - 加入好友選項（Add friend option）：開啟
4. LIFF ID 貼到 `CONFIG.LIFF_ID`
5. 萌森官方帳號的加好友連結貼到 `CONFIG.OA_ADD_FRIEND_URL`
6. （建議）Apps Script → 專案設定 → 指令碼屬性，新增 `LINE_CHANNEL_ID`＝LINE Login 的 Channel ID，後端就會驗證送出者的 LINE 身分

### 3. 官方帳號自動回應
- 關鍵字：`小水手報到`
- 回覆：一張按鈕訊息，按鈕連到 `https://liff.line.me/{LIFF_ID}`
- 攤位 QR 用預填訊息連結，掃碼後聊天室會帶入「小水手報到」

### 4. 夢想目的地的參考預算
`CONFIG.DREAMS` 是 Hotels.com 國人「此生必遊」前 10 名（OnePoll 2017 調查），每個都帶入每人參考預算（`perPerson`，單位元），依 2026/10 雄獅旅遊同類團費取整，程式碼旁有註明出處。萌森有自家行程的話，直接換成自家價格。「其他」由客人自己填目的地和預算。

### 5. 網頁放上線
任何支援 https 的靜態空間都可以（例如 GitHub Pages），把 `index.html` 和 `logo.svg` 放上去即可。

## 上線前實測清單

- [ ] 三種帳號各走一遍：沒加好友、本來就是好友、剛加入好友
- [ ] 同一個 LINE 帳號重新開啟，直接看到原本的兌換卡，不能再填一次
- [ ] 按下兌換後，3 分鐘倒數；過了 3 分鐘變成「已兌換」
- [ ] 試算表有收到資料，手機號碼開頭的 0 沒有不見
- [ ] iPhone 和 Android 的 LINE 裡各開一次，看版面與鍵盤
- [ ] 關掉網路送出：兌換卡照樣出現，恢復網路後重開會補送

## 試算公式

- 總預算＝每人預算 × 人數
- 透過萌森只需儲值＝總預算 ÷ 1.25（儲值金額加上最多 25% 回饋金，剛好等於總預算）
- 省下＝總預算 − 只需儲值
